# 🌀 Vortex-Zero Browser

E aí! Seja muito bem-vindo ao repositório oficial do **Vortex-Zero** — um navegador web moderno, leve e construído do zero em **Python** utilizando **PyQt6**. 

A ideia aqui foi juntar a paixão por desenvolvimento com a vontade de criar uma ferramenta de navegação funcional, limpa e cheia de personalidade para o dia a dia.

---

## ✨ que Recursos ele tem?

O Vortex-Zero não é só uma janelinha bonitinha, ele vem equipado com o que a gente mais usa na web:

* **🌐 Sistema de Abas Dinâmicas:** Abra quantas abas quiser, alterne entre sites e feche quando não precisar mais.
* **🔍 Barra de Pesquisa Inteligente:** Digite uma URL direto ou jogue qualquer termo para pesquisar no Google num piscar de olhos.
* **⭐ Barra de Favoritos:** Achou um site legal? Clica na estrela e salva o acesso rápido na barra dedicada logo abaixo.
* **🔇 Controle de Mute Global:** Um botão direto para silenciar ou ativar o som de todas as abas do navegador ao mesmo tempo.
* **🕵️ Modo Anônimo:** Quer privacidade? Abra uma janela isolada que não guarda histórico nem dados de navegação.

---

## 🛠️ O que foi usado para construir?

* **Python 3.x** 🐍
* **PyQt6 / PyQt6-WebEngine** (usando o motor Chromium por baixo dos panos para rodar qualquer site moderno sem engasgar).
